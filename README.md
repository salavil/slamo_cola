FEATURES

Drag to rotate the can, it spins slowly on its own
Three flavors: cola, lime, blueberry. The backdrop color changes with the flavor
Soft shadows, studio-style reflections on the metal, glossy paint
Pull tab with a finger hole and a rivet
Condensation droplets on the body
"Open the can" button: the tab lifts and a fizzy fountain shoots out, then fades away over a few seconds

RUN

Open index.html in a browser. The three.js library is loaded from cdnjs, so you need an internet connection.

NOTE

"Slamo" is a made-up brand. The can is not related to any real drink or trademark.
